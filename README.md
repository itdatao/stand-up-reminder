# 起身活动提醒 · StandUp

面向长期办公室久坐人群的 Chrome / Edge 浏览器插件：**每隔 N 分钟或 X 小时**，在浏览器里弹出提醒，让你站起来活动 3 分钟（时长可自定义），并带倒计时与每日统计。

## 功能

- **自定义频率**：输入任意数值 + 单位（分钟 / 小时），或一键选择 15 分钟 / 30 分钟 / 45 分钟 / 1 小时 / 1.5 小时 / 2 小时
- **活动时长**：1 / 3 / 5 / 10 分钟可选（默认 3 分钟）
- **浏览器内弹窗**：以 Shadow DOM 覆盖层注入当前网页，不破坏页面样式；支持「最小化」为右下角小胶囊，不打断工作
- **倒计时圆环**：显示剩余时间与进度，倒计时结束有提示音，一键「继续工作」
- **稍后提醒 / 跳过**：延后 N 分钟（默认 5 分钟）或跳过本次
- **独立休息页**：当前标签页无法注入时（如 `chrome://` 页面），自动改用独立标签页弹窗
- **系统通知兜底**：即使切换了应用，也能通过系统通知提醒，点击可回到休息界面
- **免打扰时段**：例如 18:30 → 09:00 夜间不打扰（支持跨夜）
- **电脑空闲自动延后**：检测到人不在电脑前（空闲 / 锁屏）时自动顺延，避免无效提醒
- **每日统计**：今日完成次数、活动分钟数、跳过次数 + 累计数据

## 安装（开发者模式加载）

1. 打开浏览器扩展管理页
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `stand-up-reminder/`
4. 在工具栏固定插件图标即可（图标为渐变向上箭头）

> 也可以直接把 `stand-up-reminder.zip` 解压后再按上面步骤加载。

## 使用

- 点击工具栏图标打开面板：
  - 顶部开关：一键开启 / 关闭提醒
  - 「下次提醒」：实时倒计时，可「立即休息」或「推迟 5 分钟」
  - 「提醒频率」：输入数值 + 单位，或点快捷标签
  - 「每次活动时长」：1 / 3 / 5 / 10 分钟
  - 「今日数据」：完成次数、活动分钟、跳过次数
  - 「高级设置」：弹窗 / 系统通知 / 提示音 / 空闲延后 / 免打扰时段 / 稍后提醒时长
- 到达设定时间后：当前网页顶部弹出提醒卡片 → 点「开始休息」进入倒计时 → 结束后点「继续工作」，插件自动开始下一轮计时。
- 想看弹窗长什么样：直接用浏览器打开 `demo.html`（纯 UI 预览，无需安装插件）。

## 目录结构

```
stand-up-reminder/
├─ manifest.json      # MV3 清单
├─ background.js      # 后台调度：alarms 定时、注入弹窗、通知、统计
├─ shared.js          # 共享常量与工具（频率换算、免打扰判定、统计）
├─ content.js         # 注入网页的桥接脚本
├─ break-ui.js        # 休息弹窗 UI（Shadow DOM 隔离，页面/注入通用）
├─ break.html/.js/.css# 独立休息页（无法注入时使用）
├─ popup.html/.js/.css# 设置面板
├─ demo.html          # 弹窗效果预览页（仅供查看，不参与扩展运行）
├─ icons/             # 16/32/48/128 图标
└─ tools/make_icons.py# 图标生成脚本（纯标准库）
```

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `alarms` | 定时触发提醒（后台休眠后仍可靠唤醒） |
| `storage` | 保存设置与统计 |
| `notifications` | 系统通知兜底 |
| `scripting` + `<all_urls>` | 在当前网页注入弹窗覆盖层 |
| `tabs` | 找到当前活动标签页、打开独立休息页 |
| `idle` | 检测电脑是否空闲，空闲时自动延后 |

插件不联网、不采集任何数据，所有设置与统计数据仅保存在浏览器本地（`chrome.storage.local`）。

## 自定义图标

```bash
python3 tools/make_icons.py   # 重新生成 icons/icon-{16,32,48,128}.png
```

## 常见问题

- **为什么有时是独立标签页而不是覆盖层？** 浏览器不允许在 `chrome://`、扩展商店等页面注入脚本，此时插件改用独立休息页。
- **提醒没有准时出现？** 若开启了「电脑空闲时自动延后」，在空闲状态下会延后 1 分钟再次检查；若处于免打扰时段，会顺延到时段结束后。
- **改了频率什么时候生效？** 保存后立即重新计时（正在休息或已弹出提醒时，下一轮生效）。
- **刚打开浏览器就弹窗？** 已修复：启动时会清除残留的过期定时器，并按完整间隔重新计时。

## 多语言（中/英切换）

- 在弹出面板底部「语言 / Language」下拉框可即时切换 中文 / English，设置保存在本地。
- 弹窗、系统通知、设置面板全部跟随所选语言。
- 扩展名称与描述使用 Chrome 标准的 `_locales`（`zh_CN` / `en`），在应用商店会按用户浏览器语言自动展示。

## 发布到 Chrome Web Store

1. 注册开发者账号（一次性 $5）：https://chrome.google.com/webstore/devconsole
2. 准备素材：
   - 图标 128x128（`icons/icon-128.png` 已有）
   - 至少 1 张截图（建议 1280x800，截取 popup 或弹窗效果）
   - 小宣传图 440x280（可选但建议）
3. 打包：zip 的**根目录必须直接包含 manifest.json**（可用仓库里的 `stand-up-reminder-store.zip`）。
4. 在开发者后台点「新增项」上传 zip，填写：
   - 商店描述（中英文可各写一段）
   - 分类：工具（Productivity）
   - 语言：添加 中文（简体）和 English
5. 隐私说明（审核必填）：
   - `<all_urls>` 主机权限：仅用于在当前网页注入休息弹窗，不读取、不存储页面内容
   - `storage`：仅保存本地设置与统计
   - 声明：不收集、不上传任何用户数据，无远程代码
6. 提交审核。含 `<all_urls>` 权限的扩展审查更严格，通常 1～7 天；若被要求补充「权限使用说明」，按提示提交书面说明即可。
7. 审核通过后在后台「发布」即上架。也可以选择不公开（unlisted），仅凭链接安装。

> 小范围自用可以不发布：直接开发者模式「加载已解压的扩展程序」即可，功能完全相同。
